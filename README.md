# HalgOM Screener

## מה זה
ה-HalgOM Screener הוא סורק מניות מקומי בסגנון Finviz למניות ארה"ב (מניות רגילות ותעודות ADR בבורסות NASDAQ, NYSE ו-AMEX, כ-5,000 מניות). התוכנה מציגה נתונים מ-TradingView (בעיכוב של כ-15 דקות). התוכנה מיועדת למטרות מחקר בלבד, ואינה מהווה ייעוץ השקעות.

## מה יש בו
* 4 עמודים: "סורק", "קבוצות", "מפת חום", "מדריך".
* סריקות מובנות: "ערך — זולות ורווחיות", "צמיחה איכותית", "מובילות מומנטום", "מכירת יתר במגמת עלייה", "פריצה לשיא שנתי", "דיבידנד יציב", "צמיחה במניות קטנות", "מחזור חריג", "שלב 2 (Minervini)", "ציון HalgOM גבוה".
* אפשרויות לסינון ומיון, כולל כפתור "הסתר זבל", עמודת "חדש" לתוצאות טריות מאתמול, ועמודת "אותות" (Signals).
* אפשרויות ייצוא, שמירת סריקות אישיות ("שמירת הסריקה הנוכחית בשם") וכפתור למעבר בין עברית לאנגלית.
* פירוט מלא בעמוד 'מדריך' שבתוך התוכנה.

## התקנה והפעלה ראשונה (Windows)
**הדרך הקלה: קובץ התקנה אחד.**
1. מורידים את הקובץ `install_screener.bat` מהקישור:
   https://github.com/orimaimon/HalgOM1/releases/download/installer/install_screener.bat
2. לוחצים עליו לחיצה כפולה. אם Windows מציג "Windows protected your PC", לוחצים "More info" ואז "Run anyway" (הקובץ לא חתום דיגיטלית, וזו האזהרה הרגילה לקובץ שהורד מהאינטרנט).
3. הקובץ מוריד את הגרסה העדכנית לתיקייה `AppData\Local\HalgOM` של המשתמש ומפעיל אותה: uv, Python והחבילות מותקנים לבד (בלי הרשאות מנהל ובלי git), זה לוקח דקה או שתיים. בסוף נפתח דפדפן עם הסורק, ונוצר קיצור דרך "HalgOM Screener" על שולחן העבודה. מכאן פותחים רק מקיצור הדרך.

הפעלה נוספת של `install_screener.bat` רק פותחת את הסורק המותקן ולא מתקינה שוב. אם הסורק כבר הותקן בעבר מ-ZIP בתיקייה אחרת, קובץ ההתקנה מזהה אותו לפי קיצור הדרך שעל שולחן העבודה, ופותח אותו במקום ליצור עותק חדש בלי התיקים השמורים.

**הדרך הידנית (ZIP):**
1. **הורדת התיקייה**: מקבלים את התיקייה מאורי, או מורידים אותה כקובץ ZIP ופורסים. שמרו אותה בתיקייה מקומית במחשב (למשל `C:\HalgOM`), לא בתוך Google Drive. לא צריך להתקין git: התוכנה מעדכנת את עצמה בכל הפעלה, גם אם הורדתם ZIP.
2. **הפעלה**: לחצו לחיצה כפולה על הקובץ `run_screener.bat`. בהפעלה הראשונה התוכנה תתקין אוטומטית (ללא צורך בהרשאות מנהל) את uv, את שפת Python ואת החבילות הנדרשות. תהליך זה לוקח דקה או שתיים.
3. בסיום ההתקנה ייפתח דפדפן עם הסורק. קיצור דרך "HalgOM Screener" ייווצר על שולחן העבודה בפעם הראשונה.

## פתיחה וסגירה
* **פתיחה**: לחיצה כפולה על קיצור הדרך "HalgOM Screener" בשולחן העבודה. אם התוכנה כבר רצה ברקע, היא פשוט תפתח את הדפדפן מחדש ללא הפעלת מופע שני.
* **סגירה**: לחיצה על הכפתור "יציאה" בתוך התוכנה, או סגירת החלון השחור של שורת הפקודה. התוכנה נסגרת אוטומטית 15 דקות לאחר שהלשונית האחרונה בדפדפן נסגרה.

## עדכונים
התוכנה בודקת עדכונים בכל הפעלה ומתעדכנת לבד, בלי git. אחרי עדכון החלון השחור מתחיל מחדש מעצמו. אם אין אינטרנט, או שהעדכון נכשל, התוכנה פשוט עולה בגרסה הקיימת (הפרטים נרשמים ב-`screener\_data\logs\update.log`). ניתן לדלג על עדכונים על ידי הגדרת משתנה הסביבה `SCREENER_NO_UPDATE=1`.

## איפה נשמרים הקבצים
כל הקבצים נשמרים תחת התיקייה `screener\_data` (התיקייה `_data` בתוך `screener`). כאן תוכלו למצוא:
* סריקות שנשמרו על ידכם.
* עותק של כל קובץ שיוצא דרך התוכנה (בתיקייה `exports`).
* צילומי מצב יומיים של הנתונים.
* קבצי לוג (בתיקייה `logs`).

## בעיות נפוצות
* **אין אינטרנט**: אם התוכנה כבר רצה בעבר בהצלחה, היא תציג את הנתונים האחרונים שנשמרו, יחד עם אזהרה על כך. בהפעלה הראשונה צריך חיבור לאינטרנט.
* **חלון שגיאה ("Something went wrong")**: צלמו מסך ושלחו לאורי יחד עם קובץ הלוג שנמצא ב-`screener\_data\logs\screener.log` (הקובץ `screener.log` בתיקייה `logs` תחת `_data` בתוך `screener`).
* **עיכוב בנתונים**: הנתונים מוצגים בעיכוב של כ-15 דקות.

## הבהרה
המידע והנתונים בתוכנה אינם מהווים בשום צורה או אופן ייעוץ השקעות.

## למפתחים

### מודולים ב-`screener/`

| מודול | תיאור |
|---|---|
| `fields.py` | רישום עמודות (מפתח קנוני, תווית, סוג פורמט, מקור: ספק נתונים או מחושב, טולטיפ בעברית) ותצוגות טבלה. |
| `filters.py` | פילטרים ברשימות נפתחות בסגנון Finviz. |
| `data/tradingview.py` | לקוח ישיר (requests) לסורק של TradingView. |
| `data/store.py` | ניהול מטמון (cache) וצילומי מצב יומיים. |
| `derive.py` | יצירת עמודות נגזרות (Derived columns). |
| `scores.py` | חישוב ציוני Value/Quality/Momentum וציונים באחוזונים. |
| `signals.py` | הגדרות אותות (Signals). |
| `history.py` | "חדש מאתמול" - השוואה לצילום המצב של יום המסחר הקודם. |
| `groups.py` | עמוד קבוצות ומפת חום (treemap heatmap). |
| `i18n.py` | ניהול שפת התצוגה. הנתונים הפנימיים נשארים באנגלית ורק התצוגה מתורגמת. |
| `lifecycle.py` | מנגנון "יציאה" וכלב שמירה (watchdog) לכיבוי במקרה של חוסר פעילות. |
| `update.py` | עדכון עצמי בלי git (dulwich): הופך תיקיית ZIP ל-checkout של main ומעדכן checkout נקי. SSH עם deploy key לקריאה בלבד אם קיים `%USERPROFILE%\.halgom\deploy_key`, אחרת HTTPS. |
| `market.py` | תצוגת מצב השוק וה-ADX של SPY. |
| `export.py` | ייצוא לאקסל, CSV ורשימת מעקב ל-TradingView. |
| `theme.py` | הגדרות עיצוב (מראה התוכנה וצבעים). |
| `guide.html` | מדריך המשתמש בעברית. |
| `app.py` | ממשק Streamlit. |

### הפעלה ובדיקות
```bash
uv venv --python 3.12 screener/.venv
uv pip install --python screener/.venv -r screener/requirements.lock pytest
screener/.venv/bin/python -m pytest tests/ -q
screener/.venv/bin/python -m streamlit run screener/app.py
```

### חוקים מרכזיים מתוך `CLAUDE.md`
* בקשה אחת בלבד ל-TradingView לכל 15 דקות, לעולם לא בבקשות מקבילות (parallel).
* ספקי נתונים מחזירים את מפתחות העמודות הקנוניים.
* הקובץ `run_screener.bat` חייב להישאר עם קידוד ASCII וסיומות שורות CRLF, והבתים 529-785 מוקפאים.
* ערכים פנימיים נשארים באנגלית, ורק התצוגה (UI) מתורגמת לעברית.
* שינוי שם של אלמנט בממשק דורש עדכון של הקובץ `guide.html`.
* הצבעים נלקחים מ-`theme.py`.

מפת הדרכים המלאה מפורטת בקובץ `CLAUDE.md`.
